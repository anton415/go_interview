# go_interview
Модуль курса Job4j: 4.9.6. Собеседование Go Core.

Преобразование int64 в int16 не проверяет помещается ли значение в диапазон. 
При данном преобразовании число переводится в двоичную систему и оставляется только 8 цифр справаб остольное отбрасывается.
Преобразование не вызывает панику или ошибук.
