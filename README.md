## NonZeroFields

`NonZeroFields` принимает `any`. Конкретный тип структуры и набор её полей становятся известны функции во время выполнения. Пакет `reflect` позволяет перечислить поля, прочитать их имена и теги `json` и проверить значения через `IsZero()`.

Если функция работает только с известной структурой, например `Profile`, проще обратиться к `p.Name` и `p.Age` напрямую. Тогда компилятор проверит имена и типы полей.
